# SlimeFun4.1 v4.9.4(Release Preview)

本版本聚焦代码安全性与高负载稳定性加固，无公开 API 变更、无磁盘存储格式变更。

## 安全
- 修复 Butcher Android / Farmer Android / 可编程机器人移动绕过领地限制的问题：现在攻击实体、收获作物、移动进入新方块前，均按机器人所有者校验领地权限（ATTACK_ENTITY / BREAK_BLOCK / PLACE_BLOCK），与 Miner/Woodcutter Android 既有校验保持一致
- 统一机器人 owner 读取逻辑（getOwner 上移至 ProgrammableAndroid 复用，删除 Miner/Woodcutter 中的重复实现）

## 稳定性
- 修复玩家档案(PlayerProfile)在高负载异步保存下的并发问题：
  - PlayerData 的研究/背包/路径点集合改为并发实现（ConcurrentHashMap），消除异步保存线程迭代时主线程并发修改导致的 ConcurrentModificationException
  - 引入修改纪元(modificationEpoch)：保存仅在纪元未变时清除 dirty 标志，保证保存期间并发落地的改动不会因 dirty 被误清而丢失
  - dirty / markedForDeletion 改为 volatile，修复跨线程可见性导致的偶发跳保存
  - setResearched 调整为「先改数据后标记 dirty」，使纪元始终反映数据状态

## 兼容性
- 无公开 API 变更、无磁盘存储格式变更
- 机器人移动/作业受领地限制属正确的安全行为收敛；ownerless（遗留无 owner 数据）机器人：挖/农/攻击类跳过，移动类保留旧行为
