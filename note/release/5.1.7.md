# 5.1.7

发布日期：2026-08-27
基线：v5.1.6 → v5.1.7（64-66 轮审计，5 项修复）

## 数据完整性

- 物品注册失败不再残留半注册条目：`getById` 此前可发现失败的物品、其 id 永久占位阻断修正后的重新注册。

## 稳定性

- 全局关闭 tickers（URID.enable-tickers=false）时，受影响物品现在同样清除方块处理器与 ticker 注册，不再残留可调用的处理器。
- 配方快照订阅者逐个隔离：单个附属的订阅回调抛错不再中断快照刷新、不再使排在后面的订阅者收不到配方数据。
- 配方快照跨线程可见性（volatile）。
- 多方块结构 `MultiBlock` 的 hashCode 与 equals 契约对齐（防未来哈希容器误用）。

## 实机回归

- Paper 1.21.11 独立实例启动链路零失败，全日志无 ERROR/SEVERE，优雅停机正常。
