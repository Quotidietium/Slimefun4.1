# SlimeFun4.1 v4.9.5

在 v4.9.4（安全与稳定性加固）基础上，聚焦 tick 主循环与高频热路径的性能优化，并细化测试与基准覆盖。无公开 API 变更、无磁盘存储格式变更。

## 性能
- tick 主循环：SlimefunProfiler 改为按需收集每块明细（平时只记 tick 总耗时），ticker-run（5000 块）由 ~3ms 降至 **0.76ms（约 -75%，每块 159ns）**。PlaceholderAPI timings 占位符保持实时；DebugFish 查单块耗时时需先 `/sf timings` 开启收集
- 电网结算：EnergyNet 结算循环复用 LocationInfo，新增 `setCharge(Location, Config)` 与 `BlockStorage.updateBlockInfo` 轻量写入路径，charge 写入由 ~200ns 降至 **73ns/组件（约 -63%）**
- charge 写入：`setBlockInfo` 写入同一 Config 时跳过冗余 put
- tick 调度：TickerTask 每区块只解析一次 BlockStorage，跳过每块的 world 查找
- cargo：领地校验的 owner 解析单 tick 内缓存，降低 v4.9.4 新增的每节点校验开销

> 上述均为内部实现优化。profiler 唯一可观测行为变化：DebugFish 查单块耗时时需先 `/sf timings`（诊断工作流），PlaceholderAPI 占位符实时性不变。

## 测试与基准
- 新增 13 项回归测试（profiler 按需收集、BlockStorage updateBlockInfo、EnergyNetComponent `setCharge(Config)`），全量 **1905 项通过、0 失败**
- 基准新增 3 个场景：机器加工中、电网结算 charge 写入、用户交互（方块放置/破坏），共 **8 场景**
- 完整对比见 [benchmark/report/](../../benchmark/report/)：[REPORT-4.9.4-final.md](../../benchmark/report/REPORT-4.9.4-final.md)、[PERFORMANCE-COMPARISON.md](../../benchmark/report/PERFORMANCE-COMPARISON.md)、[SCENARIOS.md](../../benchmark/report/SCENARIOS.md)
