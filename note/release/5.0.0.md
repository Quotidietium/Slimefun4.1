# SlimeFun4.1 v5.0.0

在 v4.9.5（tick 热路径性能优化）基础上，完成大规模**公开 API 扩展**：面向附属插件新增约 200 个公开事件、3 项非事件 API，并对 6 个既有事件追加可修改能力。全部为**纯增量改动**——未删除或修改任何既有公开 API 签名，无磁盘存储格式变更，无机器行为变更（未注册监听器时行为与 v4.9.5 完全一致）。

## 事件 API（约 200 个新增事件）

统一设计约定：事件均在动作发生前触发、可取消（取消即否决该动作，物品/状态保持原样）；多数事件暴露 `setXxx` 方法，允许附属插件**就地修改**本次动作的产物、消耗、时长、落点、方向等，修改只作用于当次操作，不污染共享定义。事件覆盖的领域：

- **机器与电力**：`AsyncMachineOperationStartEvent`、`MachineRecipeStartEvent`（可改操作时长）、`AutoCrafterCraft(Event|CompleteEvent)`、`AutoAnvilRepairEvent`、`AutoBrewEvent`、`AsyncAutoDisenchanterProcessEvent`、`AsyncAutoEnchantmentSelectEvent`（逐项改附魔选择）、`ComposterProcessEvent`、`DustWashProcessEvent`、`ElectricGoldPanProcessEvent`、`ProduceCollectorCollectEvent`、`ExpCollector(Collect|Produce)Event`、`CrucibleLiquidGenerateEvent`、`IgnitionChamberUseEvent`、`EnhancedFurnace(Burn|Smelt)Event`、`SmelteryFireConsumeEvent`、`GeneratorProduceByproductEvent`、`Reactor(FuelBurn|CoolantConsume|ProduceByproduct|ModeChange)Event`、`NetherStarReactorWitherEvent` 等
- **能源网络**：`EnergyGenerateEvent`、`EnergyConsumeEvent`（可改/取消单个消费者充能量）、`EnergyNetTickEvent`、`SolarHelmetChargeEvent`、`ChargingBenchChargeEvent`
- **货运网络**：`CargoItem(Withdraw|Insert)Event`（可改传输物品）、`CargoNetTickEvent`、`CargoNode(ChannelChange|FilterChange|DistributionMode|Restriction)Event`、`CargoNetVisualizerToggleEvent`
- **可编程/工业机器人**：`Android(Attack|Mine|Fish|Move|Rotate|Refuel|FuelConsume|ItemDeposit|ScriptChange|ChopTree)Event`、`ButcherAndroidKillEvent`（可改经验产量）、`IndustrialMiner(Start|Stop|Mine)Event`、`GEOMining(Start|Complete)Event`、`GEOScanEvent`、`OilPumpExtractEvent`（可改油耗）、`FluidPumpCollectEvent`
- **研究系统**：`Research(Lock|Unlock|Cost|Progress)Event`、`PlayerResearchRankChangeEvent`、`PlayerAllResearchesUnlockEvent`、`ResearchFireworkDamageEvent`、`KnowledgeTome(Bind|Share)Event`、`KnowledgeFlaskFillEvent`
- **背包**：`PlayerBackpack(Open|Close)Event`、`Backpack(Create|Resize|Restriction)Event`、`EnderBackpackOpenEvent`、`Soulbound(ItemsKeep|ItemsReturn)Event`（keep 支持按物品豁免）、`SoulboundRuneApplyEvent`
- **传送与 GPS**：`Teleportation(Start|Abort|Complete)Event`（可改目的地与时长）、`ElevatorTeleportEvent`（可改目的楼层）、`ElevatorFloorRenameEvent`、`WaypointRemoveEvent`、`GPSTransmitterStatusEvent`、`GPSNetworkComplexityEvent`、`TelepositionScrollRotateEvent`

- **食物与医疗**：`SlimefunItemConsumeEvent`、`JuiceDrinkEvent`（可保留玻璃瓶）、`(Diet|Fortune)CookieConsumeEvent`、`FortuneCookieFortuneEvent`、`(Monster|Meat)JerkyConsumeEvent`、`BandageHealEvent`、`SplintHealEvent`、`VitaminsCureEvent`、`MedicineConsumeEvent`、`CoolerSaturationEvent`、`MagicalZombiePillsCureEvent`（可改治愈时长）
- **武器与装备**：`SlimefunItemDamageEvent`、`SlimefunBow(Shoot|Hit)Event`、`ExplosiveBowExplodeEvent`、`IcyBowFreezeEvent`、`SwordOfBeheadingDropEvent`、`VampireBladeHealEvent`、`SeismicAxeShockwaveEvent`、`StormStaffStrikeEvent`、`WindStaffLaunchEvent`、`WaterStaffExtinguishEvent`、`MagicEyeOfEnderLaunchEvent`、`SlimefunArmor(Change|Effect)Event`、`RainbowArmorCycleEvent`、`SlimefunBootsFallEvent`、`StomperBoots(Bounce|Push)Event`、`ElytraImpactEvent`、`EnderBootsPearlProtectEvent`、`FarmerShoesTramplePreventEvent`、`BeeStingProtectionEvent`、`WitherProofAttackEvent`、`ParachuteSlowFallEvent`、`BeeWingsSlowFallEvent`
- **工具**：`SlimefunToolUseEvent`、`MultiToolModeSwitchEvent`、`PickaxeOfTheSeekerLocateEvent`（可重定向矿石）、`PickaxeOfVeinMiningEvent`、`SmeltersPickaxeSmeltEvent`、`LumberAxe(TreeFell|Strip)Event`、`GrapplingHook(Fire|Pull)Event`、`TapeMeasureMeasureEvent`、`SpawnerCaptureEvent`
- **祭坛与基座**：`AncientAltar(RitualStart|RitualAbort|ItemConsume)Event`（可改仪式产物）、`PedestalItem(Place|Take)Event`（可改展示/返还物品）、`EnchantmentRuneApplyEvent`、`VillagerRuneResetEvent`

## 非事件 API

- **研究前置依赖系统**：`Research#addDependency(Research)` 支持声明研究前置，未解锁前置时研究不可解锁（配套 `ResearchLockEvent` 可观测/拦截）；该检查在 `PlayerResearchTask` 统一强制——指南、知识典籍分享、`/sf research all` 与 `research.unlock()` API 均不可绕过（`/sf research all` 已按依赖序多趟解锁）
- **`ResearchBuilder` 流式构建器**：链式声明 key/name/cost/绑定物品/前置依赖，`build()` 或 `register()` 一步完成（既有 `Research` 构造器完全保留）
- **标记接口 `SlimefunWeapon` / `SlimefunFood`**（`core.attributes`）：无行为标记，附属可通过 `instanceof` 识别武器/食物；内置武器（SlimefunBow、VampireBlade、SeismicAxe、SwordOfBeheading 等）已实现 `SlimefunWeapon`

## 既有事件增强（6 个）

`AndroidMineEvent`（新增 getDrops 可改开采掉落）、`BlockPlacerPlaceEvent`（setItemStack 接线生效）、`PlayerLanguageChangeEvent`（可取消 + setNewLanguage）、`RadiationDamageEvent`（setExposure 可改有效辐射等级）、`ResearchUnlockEvent`（可改研究时长）、`TalismanActivateEvent`。均为附加性方法，签名兼容。

## 发布前全量审计（8 个维度，详见 note/audit/5.0.0-audit.md）

对物品/数值修改语义、不可信输入、并发异步、高负载稳定性、领地保护闭合、持久化损坏容错、玩家交互监听器、自动保存落盘管线、机器人脚本系统做了逐维度审计，修复 63 项缺陷（其中 12 项为上游既有，本次一并修复）：

- **事件语义归一**：货运撤回/插入事件将替换物设为空气统一为"销毁物品"语义（原行为依落地路径不一致）；`TreeAccelerateEvent` 生长加速封顶 100（原无上限可卡死 tick 线程）；`StomperBootsPushEvent` 拒绝 NaN/∞ 伤害
- **数据丢失修复**：`TrashCanVoidEvent` 豁免匹配误用忽略 meta 的 `ItemStack#equals`，会销毁被点名豁免的物品（如命名镐）；`AbstractEntityAssembler` 的 offset 存档损坏时白吃材料并可被 TickerTask 摧毁机器（上游既有）；`BlockPlacer` 的 owner 存档损坏时退化为原版发射器丢物品（上游既有）；背包 size 存档损坏时内容被静默清空（上游既有，现从内容槽位推断尺寸）
- **安全加固**：传送点纯颜色代码名（净化后空 id）写入空 YAML 键 → 拒绝并提示；45 个异步触发事件补自适应 async 声明（`isAsynchronous()` 不再误报 false）；`BlockPlacerPlaceEvent.setItemStack` 替换物重过放置规则校验（防绕过 unplaceable-blocks）；`AsyncEntityAssembleEvent.setSpawnLocation` 拒绝无世界/非有限坐标
- **玩家交互修复**：风之杖取消发射不再扣饥饿（原次序与文档相悖）；附魔符文等级越界不再吞没物品与符文；吸血剑治疗量拒绝负值（原可杀死玩家）；万能工具篡改 NBT 的模式索引回退；爆炸弓实体列表容忍非生物实体；践踏靴击退移到保护校验之后（上游既有）；6 个向量 setter 拒绝 NaN/∞ 分量
- **玩家资产与进度修复**：研究附加费/知识瓶费用超过玩家等级时失败关闭（原可致负经验）；研究时长封顶 72000t 且延迟解锁重解析 profile（原超长时长软锁 + 中途退出研究丢失）；知识典籍分享失败退还典籍（上游既有）；`ResearchUnlockEvent` 取消退还已扣等级（上游既有）；开背包越过其他库存时不再丢 dirty 追踪（上游既有，原编辑静默吞没）；背包扩容时观看者重定向到新库存（上游既有）；灵魂绑定取回不覆盖他插件物品、放不下时掉落而非吞没（上游既有）
- **落盘管线加固**：自动保存间隔非法值回退默认 10 分钟（原 0=每 tick 刷盘、负数=静默失效）；单世界保存异常隔离（原一次异常杀死整个自动保存任务，之后所有数据永久不落盘）；`PlayerProfile.save` 加锁防并发写临时文件互相截断；保存前清空背包段（原已删背包复活、物品复制）；原子写失败即删半成品临时文件（原写一半的文件可替换好文件）；删除 `.sfb` 失败重新入队（原已删方块复活成幽灵方块）；世界未加载的传送点原样保留不再被清空（上游既有，多世界数据丢失）
- **审计确认无问题**：全部"改变世界"新事件路径的 ProtectionManager 校验在事件之前且 veto 完整；命令/GUI 点击层零改动维持上游加固状态；新事件热路径监听器守卫齐全、无无界增长、无日志风暴；玩家交互路径的消耗/冷却/耐久扣除次序与 veto 回滚完整

## 兼容性

- 无既有公开 API 删除或签名变更、无磁盘存储格式变更、无机器行为变更
- 全部事件在未注册监听器时走原代码路径（多数事件触发点带监听器存在性短路，零开销）
- 既有附属插件无需任何改动
- **附属开发者注意**：部分事件触发于异步线程（机器/网络 ticker、盔甲任务、辐射任务等），其 `isAsynchronous()` 返回 `true`——监听这些事件的附属代码同样运行在异步线程，请勿在监听器中直接操作 Bukkit 世界状态，需要时应调度同步任务；各事件 Javadoc 已注明其线程上下文
