# SlimeFun4.1 v4.9.3(Release Preview)

- 性能:BlockStorage 方块数据写入改为纯内存操作,JSON 序列化推迟到保存时批量执行,电网充能写入开销降低约 4.9 倍
- 性能:方块数据文件(.sfb)视图改为持久缓存,自动保存不再每次重复解析磁盘文件
- 性能:空转机器引入配方扫描负缓存,输入无匹配配方时不再每 tick 全量比对,最高降低约 8.9 倍
- 性能:电容贴图按 4 档电量去重,同档位电量变化不再重复更新贴图,开销降低约 26 倍
- 性能:全息标签内容未变化且全息存活时跳过更新调度与实体查找,开销降低约 85 倍
- 性能:TickerTask 每方块每 tick 的 ticker 解析由 4 次降为 1 次,5000 方块完整调度周期缩短约 13%
- 性能:典型大型电网场景下,一个自动保存周期(10 分钟)的方块数据总开销约为上一版本的 1/5
- 测试:新增内置 MockBukkit 性能基准工具(benchmark/ 目录),可复现上述全部数据,附 4.9.2 与 4.9.3 对比报告
- 兼容性:无公开 API 变更、无磁盘存储格式变更、无机器行为与配方优先级变更,附属插件不受影响
- 说明:以上倍率来自内置基准工具在同环境下的新旧版本对比(详见 benchmark/report/REPORT.md),绝对数值因服务器配置而异
