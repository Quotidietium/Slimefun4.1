# SlimeFun4.1 v5.1.0

在 v5.0.0（公开 API 大扩展）基础上完成**全面汉化**：物品名、物品 lore、GUI 标题与按钮、聊天消息、指南书、命令输出、运行时状态文本全部显示为中文。全部改动为显示层与资源层，**无公开 API 签名变更、无磁盘存储格式变更、无功能行为变更**。

## 两条红线（全程遵守）

- **红线 1（存档不破坏）**：Slimefun 物品识别基于 PDC sf-id（`isItemSimilar` 对 SF 物品只比较 id + DistinctiveItem 特征，从不比较显示名/lore），研究/方块/背包数据按 key 存储——物品改名与 lore 翻译对**已有存档物品的功能完全无影响**。老存档里的英文物品继续可用（货运/配方/过滤器匹配全部照常），仅显示保持英文。
- **红线 2（交互体验一致）**：命令、GUI 操作流程、机器逻辑、研究解锁、事件语义全部不变，仅显示语言变化。

## 翻译覆盖面

- **物品定义**：`SlimefunItems` 534 个物品的显示名（与 zh-CN items.yml 一致）+ 全部 lore 逐行 1:1 翻译（行数不变，占位符/颜色码保留）；`SlimefunItemSetup` 配方图标 3 处（铁傀儡/猪灵/生日蛋糕）
- **lore 基础设施**：`LoreBuilder` 全部标签（速度/能量缓冲/输出功率/材料/范围/饥饿/剩余次数/右键提示等）与 `MachineTier`/`MachineType`/`Radioactivity` 枚举显示文本，用词与既有 zh-CN lore-phrases 严格对齐
- **GUI**：机器标题（`getInventoryTitle` 默认取物品名→自动中文）+ 6 处硬编码标题（传送器/背包/机器人脚本/反应堆端口/垃圾桶/内部容器）；货运节点（频道/黑白名单/轮询/智能填充）、反应堆与接入端口说明、机器人脚本编辑器、电梯、全息投影、实体装配机、GPS 面板、多方块结构图标
- **指南书**：指南物品名与 lore、解锁按钮/花费提示、返回页、设置/贡献者/版本/附属/问题反馈面板全部硬编码文案
- **命令**：/sf stats、/sf versions、/sf timings 输出；时间格式本地化（"2分30秒"/"1天 5小时"）
- **运行时状态**：能量/货运网络全息、GEO 采矿机全息、能量连接结果、灵魂绑定末影护身符前缀、知识典籍所有者行等
- **资源文件**：zh-CN messages.yml 补齐缺失的 `error-occurred` 键；lore-phrases 补 `Type:`/`ID:` 标签显示翻译；修正未翻译的 "lump" 术语（→碎块）
- **默认语言**：config.yml 默认 `options.language: zh-CN`（**仅影响全新安装**；既有服务器配置值不变，需手动改为 zh-CN）

## 老存档兼容机制（双语识别，共 4 处）

以下运行时"写入后再读回"的 lore 标记做了双语兼容——新物品写中文，读取同时接受英文老行与中文新行：

1. **灵魂绑定行**（`SlimefunUtils`）：新物品写 "灵魂绑定"，`isSoulbound` 同时接受英文 "Soulbound" 老行（含 PDC 双因子校验语义不变）
2. **剩余次数行**（`PatternUtils.USES_LEFT_LORE`）：正则同时匹配 "N Use(s) left" 与 "N 次 剩余"
3. **多功能工具模式行**（`MultiTool`）：模式前缀写中文，切换时的行定位正则接受英文老前缀
4. **MOB_DROP 图标名**（`RecipeType.registerMobDrop`）：配方图标名被反解析为 EntityType，新增中文别名映射（铁傀儡→IRON_GOLEM、猪灵→PIGLIN）

## 按红线保留英文的字符串（身份/格式敏感）

- 充能行 `⇨ ⚡ N / M J`（语言无关，格式为读写契约的一部分）
- 背包 ID 行 `&7ID: <ID>` 与前缀 `&7ID: `（`PlayerProfile`/`AbstractCraftingTable` 字符串匹配；指南显示层经 lore-phrases 译为"编号："）
- 刷怪笼类型行 `Type: <Type>`（`AbstractMonsterSpawner` 标签匹配；显示层译为"类型："）
- 祭坛探针前缀 `§dALTAR §3Probe - §e`（实体身份标记）
- 品牌/技术名词：Slimefun、GEO、GPS、ExoticGarden、Minecraft/Slimefun 版本标签、ms/K/M/Bn 数字单位
- 控制台日志（供日志工具解析，保持英文惯例）
