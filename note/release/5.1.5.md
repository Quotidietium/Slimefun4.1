# 5.1.5

发布日期：2026-08-27
基线：v5.1.4 → v5.1.5（59-61 轮审计，3 项缺陷修复）

## 数据完整性

- 背包改动不再可能静默丢失：关闭背包后的脏标记在当前存储路径下失效，玩家改完背包直接下线时改动会随档案一并从内存清除（已修复）。
- 自动保存不再与玩家编辑背包并发：异步保存线程改为在主线程对背包内容做快照后序列化，消除高负载下的数据竞争。

## API 正确性

- `LockedItemGroup` 的进度锁不再因附属装载顺序而静默失效：父组在子组之后注册时现在会被延迟补解析。
- `PerWorldSettingsService#save` 持久化世界级启停（随 v5.1.4 修复项重申）。
- `ItemGroup`/`Research` 同名重复注册现在输出诊断告警。

## 实机回归

- Paper 1.21.11 独立实例启动链路零失败，插件启用阶段无 ERROR/SEVERE。
